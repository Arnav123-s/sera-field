## Reading the archive

The ZIP uses relative `runs/` paths. Extract it into a **fresh review directory** to inspect records; leave the completed working run untouched. The root `runs/FIELD-001/selection.json` identifies all selected candidates. Each model directory includes `step-00000.pt`, intermediate saved checkpoints, `learning.jsonl`, `cursor.json`, `initial.json` and `result.json`. `FINALS_OPENED.json` binds the once-opened evaluation to the selected checkpoint manifest.

The original uncompressed runs remain local. The compressed archive is a portable evidence copy, not a replacement for them. The new lab's Git history retains implementation revisions; the private source intake and lease-recovery record stay local.
