## Intended behavior and measurements

| Requirement | Executable test | Interpretation |
|---|---|---|
| Shared meaning | The identical learned transition weights answer several task views | Cross-use of a learned mechanism; separate from general language understanding |
| Imagination | Roll out altered mass, force and initial conditions on immutable branches | A conditional prediction with named assumptions |
| Perspective consistency | Re-express vector observations in independent local SU(2) frames | Covariance of physical representations |
| Curiosity | Compare predictive alternatives, select a discriminating action, observe its outcome | An engineered investigation policy using learned predictions |
| Correction | Fit a successor using newly observed consequences, qualify on reserved development episodes | Measured model acquisition |
| Retention | Replay the earlier vacuum cohort and preserve the original qualified predictor | Measured retention with explicit context selection |
| Diverse answers | Keep distinguishable surviving models; deduplicate equivalent predictions and credit | Diversity of supported alternatives, not reward for aliases |
| Reward | Bind improvement credit to goal, decision, model version and independent evidence | No credit for self-agreement, repeated evidence or imagined measurements |
| Language | Produce a bounded explanation from actual numerical outputs and assumptions | Initially an engineered rendering; learned raw-language grounding is a subsequent work package |

## Subsequent capability gates

The next work package connects language grounding, learned alternative generation, investigation and reward-driven persistent updates in one owner. Adding a language encoder alone does not satisfy the requested loop. Its protocol must freeze human-source identities, supplied information, reward contracts, task families, transfer and retention checks before training. Reward-disconnected and imagination-disconnected conditions check whether those mechanisms actually improve later behavior; classical leaderboard rank is not the acceptance gate.

Representation growth from perceptual histories, a discretized effective-action flow, topological storage and a derived local eligibility mechanism remain explicit research work. They require mathematical contracts and actual implementations before being recorded as implemented components. Every new study uses an untouched cohort and preserves earlier failures. The full acceptance checklist is maintained in [BEHAVIOR_ACCEPTANCE.md](BEHAVIOR_ACCEPTANCE.md).

Completion of FIELD-001 is a usable physical-model milestone, not completion of the entire vision. I retain the larger goal and exact continuation state rather than relabeling the first experiment as the whole architecture.
