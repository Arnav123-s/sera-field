relate a cellular sheaf Laplacian's kernel to cohomology. This characterizes
compatibility under its restriction maps. For an elementary example, two scalar
nodes with identity restrictions have residual x1-x2: every pair (a,a) agrees,
including a value that disagrees with an external measurement. Thus the actual
verifier checks grounded observations or an explicitly encoded proof obligation
in addition to compatibility. Agreement supplies a useful internal signal; it
does not supply an unspecified universal algebra checker.

**Reversible and dissipative credit.** The source first advocates replacing
reversible credit, then later advocates whole-pipeline Hamiltonian echo. I retain
the mathematically specified split: echo on the reversible subflow; explicit
derivatives/eligibility or fresh trials on dissipative and measured operations.
Mass-conserving phase separation still dissipates passive free energy. No inverse
for an information-losing measurement is inferred from a Hamiltonian analogy.

**Finite anyonic computation.** [Bonderson, Freedman and Nayak](https://arxiv.org/abs/0802.0279)
construct gates using charge measurements. [Zheng, Dua and Jiang](https://arxiv.org/abs/1607.07475)
give fixed measurement sequences with outcome-dependent corrections. These support
explicit finite protocols with outcome bookkeeping. A CPU simulation still pays
for its represented state space. Preserving performance after phase scrambling
alone does not establish a quantum advantage or a specific physical substrate.

**Storage and revision.** A Chern invariant is fixed while the relevant smooth,
gapped family remains in its topological sector. That does not identify every
within-sector payload or make a learned semantic rule true. The current code and
memory tests specify which corruption is corrected and independently assess
whether retained knowledge improves its task. Valid simpler regimes are preserved
when a new supported explanation is added.

**Cross-scale analogies.** The proposed comparison between phase separation and
gravitational clustering is an analogy until a mapping of variables, equations,
constraints and observables is given. Likewise, an atmospheric vortex's longevity
does not identify a band-theoretic Chern encoding. The [Juno gravity study](https://pubmed.ncbi.nlm.nih.gov/34709940/)
measures the Great Red Spot's physical depth; it is not a memory-code theorem.
Useful candidate mechanisms can be tested without declaring these systems identical.
