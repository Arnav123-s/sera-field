## Why the new source route matters

The earlier arithmetic view taught individual operations with earlier work in
the input. Its builder also appended some unchecked annotations to a displayed
earlier-work trace. Those historical views and results remain preserved. The
new [whole-question view](CORE_022_TEACHING_VIEWS.md) checks every marked
calculation before admitting a complete program target. It never inserts a
teacher's intermediate answer into the learner's context.

The source compiler review also caught a domain issue: ignoring an unused code
assignment or replacing a zero power with one could discard a division-by-zero
obligation. Version 2 preserves evaluation of those expressions. Version 1,
its compiler bytes, report and costs remain preserved. The accepted corpus bytes
were unchanged by that repair; the new adversarial tests exercise the corrected
domain handling.

The inspected original training set contains 5,918 human math and 295 code
records. The new view qualifies 3,822 whole math questions and three scalar code
exercises, with 6,572 compatible target graphs, 11,183 checked math calculations
and nine human code assertions. Binding ambiguity remains explicit in 1,127 math
questions. The broader human programming sources still participate in attributed
reading; their reading scores and executable-program scores remain separate.
