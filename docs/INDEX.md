| Task | Guide | Recorded owner |

| Keep a goal, choose measurements and return an answer | [Persistent investigation](INQUIRY_USAGE.md) | INQUIRY-014 |

Each guide names the task, supplied inputs, assumptions and relevant evidence.
Owners remain separately addressable so a later study does not erase an earlier
working interface. Local numerical commands use the exclusive supervisor.

## Reproduce or audit

- [Frozen protocols](../protocols/) specify teaching, controls and assessment
  before final predictions are opened.
- [Implementation](../sera_field/) and [tests](../tests/) contain the numerical
  operators, learner, persistent interfaces and independent contract checks.
- [Research state](../reports/STATE.json) records current work and preserved
  owners. Individual study reports bind claims to training, cases and costs.
- [Inference checkpoints](../checkpoints/) contain selected weights and manifests.
  Complete optimizer/RNG histories and raw sources remain in the local lab.
- [Earlier detailed README](README_HISTORY_20260920.md) preserves the historical
  release account without making the main entry page a research log.
