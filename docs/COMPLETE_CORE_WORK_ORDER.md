## One state and one learning path

The candidate must own the input encoders, transient geometric situation,
covariance, fast/slow traces, active bulk, conditional alternatives, learned
investigation procedure and qualified retained knowledge. Memory operates from
the first teaching event. All trainable coordinates start freshly initialized;
previously trained owners serve as preserved references, never hidden backbones.
Reusable mathematical code is distinguished from reused learned weights.

The continuous state has a declared layout and coupled action. Each connection
needs both an executable dependency and a test showing its effect on another
part of that same state. Where memory and boundary appear in one energy, compute
both derivatives: a copied memory vector injected into an otherwise independent
solver does not establish reciprocal coupling. Reversible propagation,
dissipative settling, measured conditioning and parameter learning keep their
distinct update laws and numerical contracts.

Observations, outcome receipts and original goals remain externally auditable.
They identify what happened; learned numerical state carries the representation.
A conditional rollout copies the retained state. Only independently qualified
evidence can promote its proposed update. Storage correction protects a payload;
the independent observation or proof obligation qualifies its meaning.

## Curriculum built around the requested behavior

Every subject has observation, interpretation, conditional imagination,
investigation, independently checked correction and later reuse stages. Subjects
are interleaved so one high-volume source cannot consume the whole course.
The exact source/lesson counts, selectors, schedules, splits and numerical budget
are frozen before teaching. The source ledger distinguishes human-authored
material, supplied labels, simulated experience and generated practice.

The [new empirical synthesis](EMPIRICAL_SYNTHESIS_20260921.md) adds an explicit
single-acquired-relationship and contradiction assessment across five uses.
Its historical claims are reconciled there with the current local evidence.
Single-observation and targeted-acquisition conditions remain separate; a
measurement that identifies only an equivalence class must retain alternatives.

## Reward for accurate breadth

Reward independently verified progress on the original goal. Additional credit
requires a different valid method, explanatory assumption, consequence or useful
connection that adds coverage. Canonicalize aliases and equivalent repeated
predictions; preserve genuinely distinct methods and their conditions. Record
proposals before checking or disclosing external explanations. Novelty is
relative to the learner's recorded teaching unless a separate source audit
supports a stronger claim.

Learning-method improvement has a separate next-capability assessment at matched
teaching/evidence cost. Extra points, more branches or greater confidence are not
substitutes for that result. Failed ideas, negative credit, all attempts and
total costs are retained. Actual policy updates and their measured benefit are
reported separately.
