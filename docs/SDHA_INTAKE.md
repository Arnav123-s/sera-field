## Primary-source findings and scope

- [Yu et al., Cell Bioscience 2023](https://pubmed.ncbi.nlm.nih.gov/36991495/)
  studies a context-dependent H3K27me3/H3K4me1 transition at bivalent promoters,
  including mouse embryonic stem-cell interventions. Competing biochemical marks
  motivate a poised-state model; this is not evidence of quantum superposition.
- [Kim et al., Nature 2010](https://www.nature.com/articles/nature09342) documents
  residual tissue-of-origin memory after reprogramming. Retention and the ability
  to revise an old bias must both be measured; persistence alone is not correctness.
- [Frohoff-Huelsmann, Wrembel and Thiele](https://www.uni-muenster.de/Physik.TP/~thiele/Paper/FrWT2021pre.pdf)
  analyzes nonvariational coupling and regimes with suppressed coarsening.
  Arrest is a parameter-dependent result, not a property of every nonreciprocal
  equation. A retrieval/forgetting metric is additional to a domain-growth metric.
- [Pastawski et al., HaPPY construction](https://arxiv.org/abs/1503.06237)
  encodes bulk logical information into boundary physical degrees of freedom.
  The direction, code subspace and recoverable erasures must be explicit. A stable
  code protects represented information; an independent assessment establishes
  whether the represented scientific claim is supported.
- [Gerdes et al., version 1](https://arxiv.org/abs/2410.13161v1) gives equivariant
  continuous flows on matrix Lie groups. The current version has a changed title;
  the cited version is pinned. A continuous bijection needs compatible dimensions,
