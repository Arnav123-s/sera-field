## Coupled finite construction

One event state contains boundary multivectors and momenta, SPD covariance stalks,
a bulk density on a lattice with an extra depth axis, pending verified-capture
tags, and scoped acquired model parameters. A numerical step composes reversible
processing with explicitly dissipative covariance/memory operations. These are
different parts of one update, not a claim that dissipation is time reversible.
Memory alters the boundary source; the same transported covariance modifies that
source; temporal echo credits the resulting field; independently checked outcomes
qualify capture. Imagination alone cannot mutate the retained bulk.

The finite implementation choices are engineering contributions. The weights,
acquired representations and credited policies that change through teaching are
recorded separately. No training imports external pretrained weights.
