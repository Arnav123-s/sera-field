## Connected construction

two conserved bulk fields and the recorded conditioning of an invertible flow.
Its recall modifies the existing boundary source before the same curvature,
stationary, covariance, Clifford and temporal-echo calculations. Existing semantic
readouts and physical acquisition consume that resulting field. There is no
separate new answer model. The initial history gain is zero, preserving the parent.

The conditional flow has generator `A=diag(a_i I_3)-d D_R^T D_R`, with learned
invariant-context rates `|a_i|<=0.15`, `0<d<0.06`. `exp(A)` transports vector
fibers; `exp(-A)` is the conditional inverse and `Tr(A)` its log Jacobian.
The context is fixed during those identities. This is a finite vector-fiber CNF,
not the cited paper's complete flow on SU(N) link manifolds. The source distinction
and each state equation are recorded in the mathematical account.

Fast and slow traces exchange information bidirectionally. The fast rate is
`eta=0.02+0.48 sigmoid(r_fast)`; the slow rate is
`beta=0.002+0.08 eta sigmoid(r_slow)`, guaranteeing `beta<eta` for every parameter.
Their ranges lie in 0.02–0.5 and 0.002–0.05 respectively. Support and opposition
are separate traces of annotation-fitting progress; independent query progress
qualifies retention separately. A write injects a measured reservoir
increment. Eight subsequent NRCH steps conserve each field's mass, using dt=0.01,
periodic depth/node boundaries, stiffnesses 0.08/0.16, mobilities 1/0.5,
reciprocal coupling 0.15, pinning 0.5 and learned activity bounded by 0.8.
Interfacial stiffness is implicit. Report passive energy, mass, spectral length,

An explicitly simulated five-qubit perfect-tensor cell encodes each retained

## Human episode teaching

Use source-disjoint human SNLI groups from the already attributed training bank.
An episode teaches four independently annotated support pairs and assesses one
different query pair. All support source groups differ from the query group.
Select the supports by lexical overlap with the query text among 64 hash-selected
eligible rows; labels play no part in choosing neighbors. This supplied teaching
selection is not a claim that SERA independently acquired the curriculum.
No target enters a prediction input.
The support signal is a first-order derivative of annotation loss with respect to
the actual conditional boundary; it is detached before meta-learning. The new
continuum rates and history gain are learned through the subsequent query loss.
The earlier owner parameters remain fixed. The query objective is cross entropy
minus the detached before-loss baseline, plus 0.0001 times the explicit conditional
Gaussian reverse KL. This is negative independently annotated query-progress
reward; subtracting that fixed baseline does not change the cross-entropy gradient.
No point is awarded merely for another branch, episode or parameter update.

Seed 16116; 2,048 episodes; AdamW learning rate 0.001, weight decay 0.0001,
gradient norm cap 1. Use one episode per update, four support events in order.
Reset only the episode's conditional state; learned parameters persist. Save
optimizer, RNG, ordered source IDs, source hashes, checkpoints and cursors every
64 updates. Development: 128 distinct query source groups, assessed every 256 updates,
including the initialized candidate. Select mean query log loss, with accuracy
breaking exact ties. These supplied episode boundaries are engineering.

Final: 256 distinct query source groups untouched by SEMANTIC-015's registered
final pair selection. Draw support from the remaining untouched groups, disjoint
from all query groups. A support may recur across episodes, and exact repeats are
counted. Freeze the complete group/row IDs before model evaluation of their labels.
Use the same four support and one query row for all arms. Compare trained history,
initialized history, no history, reciprocal relaxation and equal-rate traces.
The last two are inference ablations, not separately trained architecture claims.
Report before/after accuracy, log loss, calibration, variation across source groups,
all support exposures, all attempts and every correction.

On this cohort, independently assess proposed history writes, preserve the exact
original goal, bind credit to the exact state/predictor/source and reject duplicate
credit. Only supported improvement permits factual retention. Compare clean and
corrupted encoded state using the declared code channel, including erasure-aware
reconstruction. Independently replay one full final and a persistent source/task
session. The stored history's evidence record must remain available after restart.
The delivery uses the first eight prospectively ordered development episodes,
records every attempt, and deliberately mismatches the first performed proposal.
Each query receives one assessment; neither a failed grade nor a successful grade
may be farmed for repeat credit. The stored state is used only in its original
goal scope. Check a single Pauli error and all 16 branches of the declared
two-site erasure channel through the actual returned answer, not only a scalar
round trip. A candidate with no qualified positive delivery remains preserved.

## Acceptance and continuation

No final trains or selects a model. Promotion requires mathematical/identity tests,
finite and repeatable outcomes, unchanged protected parent parameters, and no loss
of earlier task ability in an empty new scope. To claim a useful learned update,
the selected step must exceed zero, final query log loss must improve by at least
1% against disconnected history, and accuracy may decline by at most 0.02. Report
the paired query-loss difference and its uncertainty as additional evidence,
not as a tuning signal. Retained history is scoped to its
independent source and original goal. Extra structure earns no scientific credit
without measured use. Preserve an unselected candidate and investigate its failure
with a fresh protocol rather than claiming success from a component property.

This tests learning a history-update procedure on human annotation tasks and its
connection to the existing owner. Broader cross-domain transfer, autonomous
scientific concept construction, literal sheaf-cell attachment, larger holographic
networks and the full supplied behavior list remain on the governing architecture
checklist. One numerical CPU thread, 2 GiB process tree, exclusive shared lease,
no paid services and no parallel numerical job.

## Pre-experiment feasibility amendment

Before numerical mechanism tests or teaching, a labels-unused metadata inspection
found 606 untouched source groups and 1,795 records, but zero groups with eight
records. The original same-group four-support/four-query design was therefore
infeasible. It also risked exploiting SNLI's within-group label composition.
The revised design above uses four supports from other groups and one query,
preserves 256 distinct untouched query groups, and never uses labels to select
lexical neighbors. This amendment preserves the abandoned design and its reason;
no model result motivated the change.
