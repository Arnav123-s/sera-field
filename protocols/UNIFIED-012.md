## Mathematical and integration gates

1. SPD stalks use `P=exp(S)` with symmetric `S`; restrictions are orthogonal
   congruences using the same learned links as the Clifford field. Test positivity,
   adjoint identity and frame covariance, including noncommuting covariances.
2. Temporal Verlet flow uses four successive source frames and eight steps per
   frame. All timed input and loss impulses must be reversed in the correct order.
   Compare all input/parameter gradients with independent autograd in float64;
   relative tolerance 0.002 and absolute tolerance 0.00002. Preserve every failure.
3. Bulk memory uses a periodic lattice with depth four and sixteen slots. For
   relaxation with fixed boundary potential, conserve concentration and reduce the
   stated discrete Flory-Huggins free energy; reject steps outside (0,1).
4. Capture requires an accepted, independently checked positive-progress credit
   event, original goal, source/predictor identities and a fresh evidence identity.
   Duplicate, stale, imagined and failed-actuator cases must not change memory.
5. A bounded 8-bit density codec is represented by gapped two-band QWZ masses.
   Validate charge decoding numerically on a periodic momentum grid, enumerate
   quantization cost, and test gap-preserving versus gap-closing perturbations.
   It encodes a learned numerical field, not mathematical truth.
6. Memory, covariance and temporal processing must affect the actual shared task
   field. Frozen ablations disconnect these paths. Earlier exact arithmetic and
   independent evidence checks remain intact.

## Prospective teaching and assessment

Use the already qualified human corpus and its source/group splits; do not redownload
or relabel completed studies. Run 3,072 updates of batch 24 per arm using the existing
reading/arithmetical-program/pair/physical schedule. Seed 12112. Arms: coupled
candidate, matched candidate with memory capture disconnected. Both use temporal
echo and SPD geometry. A parent readback measures retention, not an equal-training
architecture ranking. Learning rate 0.00015, gradient norm cap 3. Development every
512 updates; select the lowest equal-weight mean loss ratio across reading,
mathematics, physical simulation and mean human-pair tracks. Capture is assessed
after a teaching update against the supplied independent teaching targets; it is
labelled training supervision, not newly discovered truth.

Final human groups are selected deterministically with `UNIFIED-012-final-v1`,
excluding every previously opened group recorded by earlier studies. Target 384
reading, 192 math and up to 48 per pair track; report actual eligible counts.
Physical final: 256 supported and 128 omitted systems under new generator split
`UNIFIED-012-final-v1`. No repeated checkpoint selection after final exposure.
Run inference ablations for covariance and memory on the same registered cohort,
then fresh-process exact replay of the selected candidate.

Capture teaching clarification, before training: every 32 updates the capture
policy samples keep/discard. A provisional bulk density is imagined without
mutating retained state. Independent simulator queries then grade its effect on
the original goal; signed progress trains the capture policy through CreditBridge.
Only positive independently checked progress permits capture. The disconnected
arm receives the same number of attempts but retains no proposed bulk. These
extra outcomes are teaching data with their own split/costs, not final cases.

Candidate integration requires finite outputs, source/split integrity, exact
replay, actual gradients/parameter changes in the coupled components, protected
operator correctness and no more than 0.03 absolute accuracy regression per
reading/math/mean-pair track against the parent; physical MSE at most 1.15 times
parent. A failed gate triggers diagnosis and a new prospective repair protocol,
not retroactive threshold edits. Memory benefit is reported independently;
retention alone does not establish that benefit.

One numerical CPU thread, exclusive shared lease, 2 GiB process-tree cap. Save
weights, optimizer, memory buffers, credit ledger, RNG, sampling cursors, source
identities and costs. Existing SERA and all old checkpoints stay unchanged.
