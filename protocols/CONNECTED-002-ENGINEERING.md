# CONNECTED-002 engineering contract

This protocol records engineering verification before the long curriculum. It is
not a learner capability experiment and does not reopen FIELD-001 finals.

Implement one newly initialized owner with byte/numeric inputs, a finite SU(2)
lattice action, input-conditioned closed-loop features, transient imagination,
prediction and candidate choice. Test the action derivative, local-frame loop
invariance, gradients from choice to the field and input weights, and separation
of hypothetical from observed state. Heads and encodings are supplied interfaces.

Connect delayed independently checked credit to actual owner updates through a
score-function eligibility captured before evidence arrives. Test positive credit,
stale-policy rejection, mismatched goals/predictors, failed interventions, duplicate
and renamed evidence, invalid sources, imaginary outcomes and exact resume. Reward
novelty only for a distinct verified contribution that improves an independent
assessment. The checker supplies canonical contribution and scope identities.

No dataset training or final evaluation is included in this engineering run. A
passed small contract test is not evidence of broad language comprehension,
representation discovery, philosophical interpretation or learning-to-learn.

Run all repository tests once under scripts/supervise.py, one CPU numerical thread,
2 GiB committed process tree and the existing shared lease. Preserve failure logs,
then repair genuine implementation defects and replay affected checks if needed.
