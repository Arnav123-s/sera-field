# ATTACH-018 engineering contract: actual representation attachment

This protocol is recorded while GENRE-017 is running. It does not change that
study's sources, teaching, selection, final cohorts or finite director. No
numerical work under this protocol starts until the existing director releases
the shared lease. The present protocol qualifies a mathematical transition;
it does not by itself qualify a learned growth capability.

## Construction and ownership

Implement a degree-zero cellular sheaf with explicitly listed vertices, stalk
dimensions, edges and restrictions. Adding a stalk changes the actual state
dimension. Existing ring operators may be reproduced through explicit edges;
a changed topology must not silently become a different ring.

Attach a new d=r+k dimensional stalk to one old vertex, k>0, using restrictions
B on the old vertex and R=[I_r,A] on the new stalk. This chart guarantees full
row rank without a trainable SVD or a rank-dependent null-basis orientation.
For intrinsic coordinates (x,eta,w), the new state is

    T(x,eta,w)=(x, B*x_vertex - A*eta + w, eta).

Thus the enlarged coboundary is (D*x,w); the old compatible sections and k
new compatible directions coexist. T is invertible for every finite A and B.
The old-coordinate projection recovers x exactly. The metric is
G=T^{-T}T^{-1}; its inverse has a structured application through T and T^T.
The old Euclidean energy gradient and the new restriction-disagreement gradient
remain decoupled in intrinsic coordinates before a learned coupling is added.

The operator is connected to the current owner's actual Clifford restriction
maps by a read-only adapter. No model parameters or memory are changed by this
adapter. It demonstrates that the construction addresses the retained learned
field, while avoiding a premature claim that the owner has learned to grow.

## Prospective finite checks

1. Reproduce the existing ring coboundary and adjoint using explicit edges.
2. Compare the explicit sparse application with its dense diagnostic matrix,
   including unequal stalk dimensions and adjoint inner products.
3. Verify attachment/inverse, exact old-state recovery, enlarged coboundary,
   old-section embedding and exactly k additional null directions.
4. Check the specified metric gradient against independent dense linear algebra,
   including old-flow preservation at finite time steps and new error decay.
5. Check gradients with respect to B, A and state against central differences.
6. Verify independent coordinate changes on every stalk transform restrictions,
   residuals and energy correctly; this tests a change of frame, not an action.
7. Check finite-hop propagation only for a fixed block-sparse operator with a
   verified spectral bound; reject an understated bound instead of hiding it.
8. Exercise actual SEMANTIC-015 restriction maps and original-state readouts,
   exact restart, malformed topology rejection and memory-size accounting.

Use double precision for identities (absolute tolerance 1e-10, relative 1e-9),
finite-difference tolerances 1e-6/1e-5 and float32 tolerance 3e-5/3e-5 for the
actual owner adapter. One deterministic suite, seed 18118, with failed attempts
retained. If a genuine implementation defect is repaired, preserve its failed
check and replay the affected suite. No task-final data is used by these tests.

## Behavioral integration required next

Growth must be driven by separate adequacy evidence, supply a learned source
encoder/readout for the new coordinates, give covariance and memory an explicit
addressing rule, train useful coupling, preserve the original question, and
actually retry an independently checked intervention. Comparison with the
retained owner must use fresh episodes and the same observation budget. This
behavioral protocol must be frozen before teaching; these engineering tests
cannot stand in for it. Existing exact mathematics and qualified language owners
remain available throughout.

Parameters, buffers, transient state, solver scratch and supervised process-tree
costs are reported separately. This construction is called a full-row-rank cell
attachment, not Schubert splitting or a proof of semantic truth.
