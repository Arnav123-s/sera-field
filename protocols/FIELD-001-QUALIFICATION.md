# Development qualification of context use

This package is fixed before opening finals. The learned successor is compared with the preserved predictor on both new and vacuum development contexts. It is not enough to preserve the earlier tensors if ordinary old observations activate an unnecessary correction.

I measure this failure directly. A compatibility threshold is calibrated once at the 99.5th percentile of the third context statistic (normalized observed residual energy) over 2,048 fresh vacuum support windows, six observations each, seed 79092026. No hidden medium label is available at inference. The gate uses measured support residuals and does not inspect the query's outcome.

Below that threshold the owner uses its preserved physical field; above it the learned residual field participates. The architecture and threshold rule are supplied engineering. The threshold value is acquired from calibration evidence. The selected physical link weights are unchanged. Every raw candidate, its vacuum errors and its original checkpoint remain preserved.

On the already designated development cohort, retain the qualification only if it preserves at least 50% new-context error reduction, does not worsen the raw successor's new-context error by more than 5%, and keeps vacuum error below 1.25 times the old field's error. If this test fails, record it and do not silently expose the successor as qualified. No quantile sweep, final feedback or retraining is permitted by this package. Store both ungated and gated development/final results and the exact calibration identities.
